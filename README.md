# AirOS em-breve Linux Station
Um Sistema Operacional Baseado em Ubuntu focado na eficiência

## ✅ O que mudou:
- Remoção completa do sistema Snap e todos os pacotes Snap
- Remoção de bloatware e programas pré-instalados desnecessários
- Sistema base limpo com GNOME sem peso
- Navegador Brave como padrão
- GNOME Software com suporte a Flatpak
